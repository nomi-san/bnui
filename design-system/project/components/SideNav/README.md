# SideNav

Vertical navigation for dashboards and filter lists.

**Provide:** items with a 20px icon and a label, the current item (`aria-current="page"`), and optional dividers between groups.

- Default (`bn-nav`, `sidebar-width`): 48px rows, `body-md` `text-primary`; hover `surface-strong`; current `surface-highest` + 4px `accent` left bar; disabled `text-disabled`.
- Compact (`bn-nav--compact`) for filters: 29px rows, 14px `text-secondary`, a `bn-count` pill on the right; hover `fill`; current `fill`, bold `text-primary`, 2px `accent` left bar.
- Groups are separated by a `line-subtle` divider.

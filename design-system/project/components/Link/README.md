# Link

Text links in `accent`, bold, underlined under the baseline; hover moves to `accent-ring`.

**Provide:** the destination and a label that names it ("Forgot password?", "Payment Methods").

- Inline in prose: `bn-link`. Standalone helper links under fields: `bn-link bn-link--plain` (no underline) at `body-sm-strong`.
- Panel header links end in a 10px chevron (`bn-panel__link`).
- External destinations end in the external icon at .75em.
- `bn-link--subtle` (`text-muted` → `text-tertiary` + underline) for breadcrumbs and fine-print links.

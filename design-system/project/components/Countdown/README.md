# Countdown

Time left until a launch, in white digit tiles.

**Provide:** the target time; render days, hours, minutes, seconds.

- 40×40 tiles in `text-primary` with `surface-sunken` digits (`countdown` style, tabular figures), `radius-xs`; colons in `heading-md` `text-primary` between tiles. Optional unit labels below in uppercase `button-sm` `text-secondary`.
- Use it in the bottom announcement banner next to the launch headline and a primary CTA; hide it when the time has passed.

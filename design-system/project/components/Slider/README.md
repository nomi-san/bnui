# Slider

Continuous values such as volume.

**Provide:** a `label` above, the value as `--value` (a percentage), and keyboard support (arrow keys) on the real input you wrap.

- Track 3px `line-strong`; filled part and the 16px thumb are `accent`. Hover adds a 4px `fill-strong` halo to the thumb.
- Pair it with a select on the same row ("Output device" + "Volume"), `space-6` apart.

# Radio

One choice from a short list (two to five options).

**Provide:** a group label and option labels.

- 20px circle on `surface-page`, 1px `line-strong` border (hover `text-muted`); selected shows a 12px `accent` dot.
- Labels are `body-sm`: `text-secondary`, `text-primary` on hover, `text-body` when selected.
- For choices with a price or a description, use `OptionCard` instead.

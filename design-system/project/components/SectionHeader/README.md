# SectionHeader

Title row above a carousel or grid, with an optional shortcut and arrows.

**Provide:** the section title and, optionally, a shortcut ("Visit Shop", "See All Games") and the carousel's previous/next handlers.

- Title `heading-lg` (app) or `heading-xl` (web) in `text-primary`, left. Right: a `bn-btn--tertiary bn-btn--sm` shortcut and two 32px ghost arrow buttons, `space-2` apart; the previous arrow is disabled at the start.
- Leave `space-4` between the header and the content.

# Price

Prices in the `price` style with tabular figures.

**Provide:** the amount, and optionally a "From" prefix or a "/month" suffix.

- `text-primary`, 24/29, weight 500. Prefix sits 6px before the amount at the same size; suffix is 16px `text-secondary`.
- On cards the price sits at the bottom of the card, `space-6` above the edge.

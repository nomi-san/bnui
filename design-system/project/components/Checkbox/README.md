# Checkbox

On/off settings and multi-select filters.

**Provide:** a label in sentence case ("Pause updates when I launch a game") and, for dependent options, nest the child with `bn-check--nested`.

- Box: 20px, `surface-sunken`, 1px `line-hover` border, `radius-sm`. Hover border `accent`.
- Checked: an `accent` tick, no fill. Disabled: border `line-subtle`, label `text-disabled`.
- Label is `body-sm` in `text-body`, `space-3` from the box. The whole row is the click target.

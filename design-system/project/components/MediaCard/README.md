# MediaCard

Cards without a backplate for videos and features, and the horizontal featured card.

**Provide:** 16:9 media, optional badge and play badge (video), the franchise line, a title, and an optional description.

- Video card (`bn-card bn-card--plain`): media `radius-md`, NEW badge top-left, 24px play badge bottom-right (`overlay-strong`), title `heading-xs`. Feature card: title `heading-md`, description `body-xs` `text-secondary`.
- Horizontal card (`bn-card--horizontal`): 60% media / 40% content, padding `space-8`, title `heading-xl`. Use it when a section holds a single featured item.
- Hover: media `brightness(1.1)` only (plain), plus backplate step (horizontal).

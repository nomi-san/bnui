# ProgressRing

Completion of a checklist (account security, onboarding).

**Provide:** the percentage and a one-word caption ("COMPLETE").

- 160px ring, 8px stroke: track `fill-strong`, value `accent-fill`, `success` at 100% (`bn-ring--complete`). Number `display-lg`, caption uppercase 14/16 bold, `space-2` below.
- Pair it with the checklist it measures: 36px status icons (`success` check for done, `fill-strong` plus for to-do) and links for the open items.

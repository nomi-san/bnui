# Badge

One- or two-word labels on media: release state and counters.

**Provide:** the label. Badges are uppercase `eyebrow`-weight text.

- `bn-badge--urgent` (`danger` + `on-danger`): PRE-PURCHASE, BETA. `bn-badge--positive` (`success` + `on-success`): NEW. `bn-badge--neutral` (`surface-raised` + `text-primary`): counters such as "1 / 18".
- 24px tall, `radius-md`, 1px inset `line-strong` edge so it holds on any artwork. Place at the media's top-left with a `space-1` inset.

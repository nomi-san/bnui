# NewsRow

Articles as horizontal rows: image left, text right.

**Provide:** 16:9 image, title, one or two lines of summary, and the publish date.

- Grid `320px 1fr`, gap `space-6`, max width 960px, rows stacked `space-6` apart. Image `radius-md`, `brightness(1.1)` on hover.
- Title `heading-xl` at 24/29, summary `body-sm` `text-secondary`, date `body-xs` `text-muted` `space-6` below.

# Panel

Two-tone dashboard card: a header strip with a title and a link, and a body.

**Provide:** the title, an optional header link ("Payment Methods ›"), and the body content.

- Header `surface-strong`, padding `space-8` × `space-10`, title `heading-lg` at 20/24. Body `surface-raised`, padding 27px `space-10` `space-8`. Radius `radius-panel`, no border, no shadow.
- Lay panels in a two-column grid with `space-6` gaps; let a panel span both columns for lists such as recent purchases.
- Amounts use `success` at 24/32 Noto Sans.
